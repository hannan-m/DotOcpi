# Guides

Step-by-step guides for common eMSP workflows.
{: .fs-6 .fw-300 }

These guides walk you through the core operations your eMSP will perform:

- **[Registration](registration)** — Connect to a CPO with the OCPI handshake
- **[Receiving Data](receiving-data)** — Handle location, session, CDR, and tariff pushes from CPOs
- **[Pulling Data](pulling-data)** — Pull and sync data from CPOs
- **[Sending Commands](sending-commands)** — Start/stop sessions, reserve connectors, unlock connectors
- **[Token Management](token-management)** — Understand the Token A/B/C lifecycle
- **[Multi-Version Support](multi-version)** — Run multiple OCPI versions side-by-side
