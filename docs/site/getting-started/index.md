# Getting Started

Get up and running with DotOcpi in minutes.
{: .fs-6 .fw-300 }

DotOcpi is a .NET library that implements the [OCPI protocol](https://github.com/ocpi/ocpi) for **eMSP (e-Mobility Service Provider)** applications. This section walks you through installation, basic configuration, and your first CPO registration.

---

## What You'll Need

- **.NET 8.0** (LTS) or **.NET 10.0** (LTS)
- An ASP.NET Core application (for receiving CPO pushes)
- A pre-shared **Token A** from each CPO you want to connect to

## Steps

1. [Install the NuGet packages](/DotOcpi/getting-started/installation/)
2. [Run through the quick start](/DotOcpi/getting-started/quick-start/)
3. [Configure for your environment](/DotOcpi/getting-started/configuration/)
